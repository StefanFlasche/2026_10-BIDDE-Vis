# Data Visualisation in Infectious Disease Analytics & Modelling
**Interactive Reveal.js Presentation**

Converted from `Presentation1.pptx` into a modern, responsive HTML5 / Reveal.js presentation.

---

## 🚀 How to View

### Option 1: Open Directly in Browser
Double-click `index.html` or run:
```bash
open index.html
```

### Option 2: Run a Local Web Server
```bash
python3 -m http.server 8000
```
Then open [http://localhost:8000](http://localhost:8000) in your browser.

## ⌨️ Presentation Keyboard Shortcuts

| Key | Action |
|---|---|
| **Space** / **→** | Next slide |
| **←** | Previous slide |
| **↓** / **↑** | Navigate vertical sub-slides (deep dive into why & how) |
| **ESC** / **O** | Slide overview grid mode |
| **F** | Toggle full screen |
| **S** | Open Speaker View (with speaker notes & timer) |
| **Alt + Click** / **Ctrl + Click** | Zoom into any figure or detail |
| **B** / **.** | Blackout screen (pause presentation) |
| **?** | Show all Reveal.js shortcuts |
